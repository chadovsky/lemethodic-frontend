# Card icons

Small 3D icons rendered inside the selectable cards on screens 1 (LanguageSelect) and 2 (TCFGoalSelect). Must be transparent-background PNGs — they sit directly on the card's translucent-white surface with a subtle drop shadow.

Source: **Microsoft Fluent Emoji 3D** — https://github.com/microsoft/fluentui-emoji. In that repo, the 3D variants live under `assets/<Name>/3D/<name>_3d.png`.

| File | Card | Source path in fluentui-emoji |
| ---- | ---- | ----------------------------- |
| `flag-uk.png`         | LanguageSelect · English     | `assets/Flag United Kingdom/3D/flag_united_kingdom_3d.png` |
| `flag-spain.png`      | LanguageSelect · Español     | `assets/Flag Spain/3D/flag_spain_3d.png` |
| `flag-canada.png`     | TCFGoalSelect · Canadian immigration | `assets/Flag Canada/3D/flag_canada_3d.png` |
| `graduation-cap.png`  | TCFGoalSelect · Studies in France    | `assets/Graduation cap/3D/graduation_cap_3d.png` |
| `globe.png`           | TCFGoalSelect · General French level | `assets/Globe showing Europe-Africa/3D/globe_showing_europe_africa_3d.png` |

After downloading, rename each to the filename in the table above and drop it in this folder.
