# Headline illustrations

Each onboarding screen renders one of these 3D illustrations as its headline image. They must be transparent-background PNGs at 512×512 or higher so they float directly on the pastel screen bg with only a drop shadow beneath.

Source: **3dicons.co** — pick the "3D Fluent" or "Clay" style for visual consistency across the flow.

| File | Screen | 3dicons.co URL |
| ---- | ------ | -------------- |
| `speech-bubble.png` | 1 · LanguageSelect | https://3dicons.co/icons/speech-bubble |
| `passport.png`      | 2 · TCFGoalSelect | https://3dicons.co/icons/passport |
| `stairs.png`        | 3 · CurrentLevelSelect | https://3dicons.co/icons/stairs (or /stepping-stones) |
| `target.png`        | 4 · TargetScoreSelect | https://3dicons.co/icons/target |
| `calendar.png`      | 5 · ExamDateSelect | https://3dicons.co/icons/calendar |
| `key.png`           | 6 · EcoleReveal | https://3dicons.co/icons/key |

After downloading, rename each to the filename in the table above and drop it in this folder. Until the files are in place, these screens render broken-image icons — that's intentional so the asset gap is visible.

Do not commit JPGs here. Transparent PNGs only.
